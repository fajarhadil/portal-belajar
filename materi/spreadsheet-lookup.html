Analisis Data Lanjutan

Kelas 8 | Buku Informatika Revisi | Pengolah Angka

Menjadi "Detektif" Data!

Pernahkah kamu bertanya bagaimana kasir Indomaret hanya dengan men-scan barcode, nama barang dan harganya langsung muncul di layar? Atau bagaimana game mengetahui stat heromu dari ID pemain? Rahasianya ada di fungsi **Pencarian Data (Lookup)**.

🎯 Misi Hari Ini:

  • ✅ Membedakan tabel Vertikal (V) dan Horizontal (H).
  • ✅ Menguasai jurus VLOOKUP dan HLOOKUP.
  • ✅ Menguasai pelacak canggih: MATCH dan INDEX.
  • ✅ Menggunakan rumus pilihan ganda: CHOOSE.

📚 Bagian 1: Mesin Pencari Data

Bayangkan kamu punya ribuan data siswa atau data Hero. Akan sangat capek jika mencarinya manual satu per satu. Di sinilah fungsi LOOKUP (Melihat/Mencari) bekerja.

⬇️ VLOOKUP (Vertical Lookup)

Digunakan jika bentuk datamu memanjang ke bawah (Judul tabel ada di paling atas).

=VLOOKUP( YangDicari, AreaTabel, Kolom_Ke_Berapa, 0 )
  • YangDicari: Kunci pencariannya (Misal: Kode Hero).
  • AreaTabel: Seluruh tabel tempat data bersembunyi.
  • Kolom_Ke_Berapa: Data yang mau diambil ada di kolom nomor berapa?
  • 0 (False): Memastikan pencarian harus SAMA PERSIS.

➡️ HLOOKUP (Horizontal Lookup)

Digunakan jika bentuk datamu memanjang ke samping (Judul tabel ada di paling kiri). Rumusnya sama persis dengan VLOOKUP, bedanya kita menghitung Baris, bukan kolom.

=HLOOKUP( YangDicari, AreaTabel, Baris_Ke_Berapa, 0 )

⚠️ Ingat Aturan Utama!

"YangDicari" (Kata Kunci) wajib berada di kolom atau baris PERTAMA dari tabel referensi. Jika kunci pencariannya ada di tengah-tengah tabel, VLOOKUP akan gagal total (Error #N/A).

🎯 Bagian 2: Jurus Kelas Atas

Karena VLOOKUP punya kelemahan (kata kunci harus selalu di kolom pertama), maka para ahli Excel menciptakan duet maut: INDEX dan MATCH.

🔍 MATCH (Mencari Posisi)

Fungsi MATCH tugasnya hanya satu: memberitahu kamu "Di urutan ke-berapa data itu berada?"

=MATCH("Grock", A1:A10, 0)

Hasilnya misalnya: 4 (Artinya Grock ada di urutan ke-4).

🎯 INDEX (Mengambil Isi)

Sebaliknya, INDEX bertugas mengambil isi data berdasarkan nomor baris/kolom yang kita sebutkan.

=INDEX(B1:B10, 4)

Mengambil data di list B, yang berada di urutan ke-4.

🎰 CHOOSE (Pilihan Instan)

Rumus ini seperti memilih hadiah di kotak. Kamu memasukkan nomor urut, lalu CHOOSE akan memunculkan nilai dari urutan tersebut.

=CHOOSE(2, "Emas", "Perak", "Perunggu")

Karena kita mengetik angka 2 di depan, maka hasil yang keluar adalah "Perak".
