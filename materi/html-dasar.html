HTML Dasar (Edisi Lengkap)

Kelas 8 | Fase D | Rekayasa Teknologi Web

Selamat Datang di Dunia Web Developer!

Setiap aplikasi keren seperti TikTok, Instagram, hingga web Top Up game ML dibangun dari sebuah kerangka dasar bernama HTML. Hari ini, kamu akan belajar menyusun kerangka tersebut, dari teks biasa hingga menyisipkan Video YouTube!

🎯 Target Keahlianmu Hari Ini:

  • ✅ Memahami anatomi HTML (html, head, body).
  • ✅ Mahir merapikan teks (Tebal, Miring, Garis Bawah, Paragraf).
  • ✅ Mampu memasukkan Gambar, Link, dan Video.
  • ✅ Final Boss: Membangun Halaman Profil Digital Komplit di Live Coding!

📚 Bagian 1: Anatomi & Format Teks

🤖 Struktur "Manusia" HTML

Website yang valid HARUS memiliki 3 bungkus utama ini:

<html> <head> <title>Nama di Tab Browser</title> </head> <body> Semua isi website yang dilihat pengunjung ditaruh di sini! </body> </html>

✏️ Membuat Teks & Dekorasi

Di dalam <body>, kita tidak bisa langsung mengetik seperti di Microsoft Word. Kita butuh "Tag" (Penanda).

1. Judul & Paragraf

<h1>Judul Terbesar</h1>
<h6>Judul Terkecil</h6>
<p>Untuk paragraf panjang</p>

2. Format Teks (Dekorasi)

<b>Teks Tebal (Bold)</b>
<i>Teks Miring (Italic)</i>
<u>Garis Bawah (Underline)</u>

✂️ Tag Spasi & Garis (Tag Jomblo)

Sebagian besar tag harus ditutup pakai /, tapi ada tag unik yang berdiri sendiri (tidak butuh penutup):

  • <br> (Break): Untuk pindah baris (seperti tombol Enter).
  • <hr> (Horizontal Rule): Untuk membuat garis lurus pembatas.

🖼️ Bagian 2: Gambar, Video, & Tabel

🔗 Link & Gambar

Link: Menggunakan tag <a href="..."> (Anchor).

Gambar: Menggunakan tag <img src="..."> (Tanpa penutup).

<a href="https://google.com">Buka Google</a> <img src="foto-kucing.jpg" width="200">

▶️ Menyisipkan Video YouTube

Mau menampilkan video di webmu? Sangat mudah! Gunakan tag <iframe>. Kamu bisa mendapatkan kodenya dengan klik "Bagikan" -> "Sematkan" (Embed) di YouTube.

<iframe width="300" height="200" src="https://www.youtube.com/embed/XXXXXX"></iframe>

📊 Membuat Tabel Data

Tabel sangat penting untuk menyusun data jadwal pelajaran atau skor game. Butuh 3 tag untuk membuatnya:

  • <table> : Kotak utama pembungkus tabel.
  • <tr> (Table Row) : Membuat Baris (mendatar).
  • <td> (Table Data) : Membuat Kolom (kotak isi data).
<table border="1">
  <tr>
    <td>Nama</td>
    <td>Kelas</td>
  </tr>
</table>
Hasilnya:
NamaKelas
