HTML Dasar: Kerangka Website

Kelas: 8 Web Developer

1. Apa itu HTML?

HTML (HyperText Markup Language) adalah kerangka dasar dari semua website di internet. Jika website diibaratkan sebagai sebuah rumah, maka HTML adalah tiang, dinding, dan pondasinya.

2. Struktur Dasar HTML

Setiap dokumen web selalu diawali dengan struktur wajib seperti di bawah ini:

<!DOCTYPE html>
<html>
<head>
    <title>Judul Web</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
    <p>Ini adalah website pertamaku.</p>
</body>
</html>

3. Tag Penting yang Sering Dipakai

  • <h1> sampai <h6>: Untuk membuat judul (Heading).
  • <p>: Untuk membuat paragraf teks biasa.
  • <a href="...">: Untuk membuat *link* yang bisa diklik.
  • <img src="...">: Untuk menampilkan gambar.
