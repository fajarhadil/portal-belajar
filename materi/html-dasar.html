HTML Dasar

Tujuan: Siswa mampu membuat struktur dasar website menggunakan tag esensial HTML.

1. Apersepsi (5 Menit)

Pernahkah kalian melihat kerangka rumah sebelum temboknya dibangun? HTML adalah "kerangka" dari setiap website yang ada di internet.

2. Konsep & Demonstrasi (10 Menit)

HTML menggunakan tanda kurung sudut yang disebut Tag. Contohnya:

<h1>Ini Judul Website</h1>
<p>Ini adalah paragraf.</p>

3. Praktik (20 Menit)

💻 Siswa Laptop (VS Code):
Buat file index.html. Ketik tanda seru ! lalu tekan Tab. Tambahkan tag <h1> di dalam tag body. Buka hasilnya dengan Live Server.

📱 Siswa HP (StackBlitz):
Buka browser HP. Tulis kode HTML dasar langsung di editor, dan lihat hasilnya muncul seketika di layar preview.

4. Challenge (5 Menit)

Ubah teks "Ini Judul Website" menjadi nama lengkap kalian masing-masing. Jika sudah berhasil, tekan tombol selesai di bawah.
