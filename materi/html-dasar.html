📚 Bagian 1: Anatomi HTML

HTML (HyperText Markup Language) adalah bahasa "penanda". Bayangkan HTML seperti robot kosong yang belum dicat. Untuk merakit robot ini, kita membutuhkan bagian tubuh utama.

🤖 Struktur Manusia HTML

Website yang valid HARUS memiliki 3 bungkus utama ini:

<html> <head> <title>Judul di Tab Browser</title> </head> <body> Semua yang DILIHAT PENGUNJUNG ditaruh di sini! </body> </html>

Penjelasan:
1. <html>: Kulit terluar yang membungkus seluruh tubuh.
2. <head>: Otak sistem. Berisi hal penting tapi tidak terlihat langsung di layar (seperti nama tab di atas browser).
3. <body>: Badan utama. Teks, foto, video, dan tombol semuanya WAJIB masuk ke dalam tag body ini.

Mengisi Body dengan Teks

Di dalam <body>, kita tidak boleh sembarangan menulis. Kita harus memberi tahu browser, apakah teks itu sebuah "Judul Besar" atau sekadar "Paragraf biasa".

1. Heading (Judul)

Gunakan tag <h1> sampai <h6>. Angka 1 paling besar, angka 6 paling kecil.

<h1>Berita Utama</h1>

2. Paragraph (Paragraf)

Digunakan untuk teks panjang atau penjelasan. Gunakan tag <p>.

<p>Ini teks panjang...</p>

⚠️ Aturan Emas Web Developer

Setiap kali membuka tag, kamu wajib menutupnya dengan tanda garis miring (slash /). Jika kamu mengetik <h1>, maka di akhir kalimat harus ditutup dengan </h1>. Jika lupa, seluruh tampilan websitemu bisa hancur berantakan!

🖼️ Bagian 2: Memasukkan Gambar & Link

Website yang isinya cuma teks pasti membosankan. Mari pelajari cara memasukkan gambar dan membuat tombol yang bisa diklik (Hyperlink).

📸 Menampilkan Gambar (Tag img)

Tag gambar sangat spesial karena dia tidak butuh tag penutup. Namun, dia wajib memiliki "atribut" bernama src (source/sumber) agar browser tahu gambar mana yang harus dimuat.

<img src="link-gambar.jpg" width="300">

*Atribut width opsional, digunakan untuk mengatur lebar gambar.

🔗 Membuat Tautan (Tag a / Anchor)

Ingin teks atau tulisanmu bisa diklik dan pindah ke halaman lain (seperti pindah ke YouTube)? Gunakan tag <a> dengan atribut href (hypertext reference).

<a href="https://youtube.com">Klik untuk Buka YouTube</a>

📋 Membuat Daftar Barang (List)

Untuk membuat urutan seperti "Top 3 Game Favorit", kita gunakan perpaduan tag <ul> (Unordered List - tanpa angka) atau <ol> (Ordered List - pakai angka), yang di dalamnya diisi dengan <li> (List Item).

<ol> <li>Mobile Legends</li> <li>Valorant</li> <li>Minecraft</li> </ol>
