Mari Membangun Pondasi Website!

Setiap aplikasi canggih, game online, dan media sosial berawal dari satu bahasa dasar: HTML. Hari ini, kita akan membangun "kerangka rumah" digital pertamamu.

🎯 Tujuan Pembelajaran

Setelah menyelesaikan misi ini, kamu akan mampu:

  • ☐ Memahami fungsi HTML sebagai kerangka website.
  • ☐ Menyusun struktur dasar (html, head, body) dengan benar.
  • ☐ Menggunakan tag judul (Heading) dan paragraf untuk menampilkan teks.

📚 Teori: Struktur Anatomi HTML

HTML (HyperText Markup Language) bukanlah bahasa pemrograman yang rumit, melainkan bahasa *Markup* (penanda). Tugas utamanya adalah memberi tahu browser (seperti Chrome) struktur halaman web.

📌 Konsep "Manusia HTML"

Cara paling gampang mengingat struktur HTML adalah dengan membayangkannya seperti tubuh manusia atau rumah:

  • <html> : Kulit terluar yang membungkus seluruh tubuh.
  • <head> : Otak / Kepala. Berisi pikiran rahasia (judul tab browser, koneksi sistem) yang tidak terlihat langsung oleh orang lain.
  • <body> : Tubuh. Segala sesuatu yang BISA DILIHAT pengunjung (teks, gambar, tombol) wajib ditaruh di sini.

✍️ Tag Wajib Pemula

Saat mengisi bagian <body>, kita menggunakan tag (penanda):

<h1> Ini Judul Utama </h1>

<p> Ini adalah sebuah paragraf biasa. </p>

⚠️ Awas Kesalahan Umum: Jangan lupa garis miring (slash /) pada tag penutup!

🎮 Simulasi Struktur HTML

Ayo kita rakit anatomi HTML! Tekan tombol di bawah secara berurutan untuk melihat bagaimana struktur terbentuk.

💻 Misi Live Coding

Kerangka sudah siap! Sekarang, tambahkan tag <h1> (Judul) dan <p> (Paragraf) di dalam tag <body>.
